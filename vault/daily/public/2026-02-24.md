## Technical Decisions Made

### Query Router Design
Designed a four-pattern query routing system that decides which store
leads for a given query:
- Pattern A: SQLite only — aggregation, counting, trend queries
- Pattern B: ChromaDB only — open semantic/similarity search
- Pattern C: SQLite first → ChromaDB — date range scoping then semantic retrieval
- Pattern D: ChromaDB first → SQLite — meaning leads, structured facts enrich

Key insight: date ranges always make SQLite go first — scoping ChromaDB
to known dates is more efficient and precise than open vector search.

### Storage Design
Two complementary stores with a shared `date` key:
- SQLite: composite primary key `(date, sensitivity)` — prevents
  public/sensitive collision on same date
- ChromaDB: chunk IDs prefixed with sensitivity
  (`public_2026-02-24_chunk_0`) — same collision prevention at
  vector store level

### Pre-commit Hook Strategy
Layered code quality and security guardrails:
- `ruff-format` + `ruff lint` for consistent Python style
- `detect-secrets` for credential scanning across all tracked files
- Custom public summary scanner — config-driven pattern matching
  with allowlist-before-blocklist evaluation and severity levels
  (critical/high block commit, warning logs only)

### Config-Driven Security Scanner
Moved all detection patterns out of code into `config.yaml`:
- Allowlist checked first — public GitHub repos, cloud docs, arxiv etc
- Blocklist with severity levels — critical (API keys, passwords),
  high (internal URLs, emails, AWS ARNs), warning (internal IPs)
- Private domains always blocked regardless of allowlist
- Zero code changes needed to tune scanner behaviour

## Research Notes

### Why Composite Primary Key Matters
Using `(date, sensitivity)` as composite PK in SQLite means public
and sensitive summaries for the same day are stored as independent
records. Single `date` PK silently overwrites — a subtle but critical
bug caught before Phase 2 data would have been corrupted.

### uv for Python Dependency Management
`uv` replaces pip + venv + pip-tools in one tool. 10-100x faster
installs, lockfile built-in (`uv.lock`), `pyproject.toml` native.
`[project.scripts]` in pyproject.toml gives a clean `brain` CLI
command without `python cli.py` prefix.

### Pre-commit as Last Line of Defence
Pre-commit hooks run on every `git commit` — not optional, not
forgettable. The public summary scanner specifically targets
`daily/public/*.md` files, which is the highest-risk surface for
accidental sensitive data leakage into the repo.
